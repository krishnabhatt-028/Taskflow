# TaskFlow Overview

TaskFlow is a project management platform where companies manage
projects, assign tasks, and track progress.

## Roles
- Admin: manages organization, members, all projects
- Project Manager: manages own projects and tasks
- Employee: works on assigned tasks

## Tech Stack
React, Vite, Tailwind, Node.js, Express, MongoDB, Socket.io

## Rules
- Every record has an organizationId
- Backend checks permissions, never trust the frontend
